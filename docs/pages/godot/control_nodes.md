# <div class="icon" style="mask-image: url(./medias/icons/control-icon.svg)"></div> L'interface utilisateur

L'interface utilisateur ou **UI** <span style="font-size: 0.8em; color: var(--body-text-color-faded)">(User Interface. Parfois GUI: Graphical User Inteface)</span> représente tous les éléments avec lequel l'utilisateur **intéragit**.

<br>

Dans ![Godot](../../medias/godot-logo.svg) **Godot**, pour créer toute sorte d'**UI**, on va utiliser les nodes [![Control](../../medias/godot-icons/Control.svg) Control](#godot/nodes.md#control). Les nodes [![Control](../../medias/godot-icons/Control.svg) Control](#godot/nodes.md#control) sont des **boutons**, **textes**, **images** mais surtout des **conteneurs** qui permettent de mettre en page des éléments.
