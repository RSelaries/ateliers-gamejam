# <div class="icon" style="mask-image: url(./medias/icons/git-icon.svg)"></div> Version Control

Le **version control** est le fait de garder une trace de chaque modification apportée à un document. Cela permet de revenir en arrière très facilement en cas de problème et c'est un très bon outil pour travailler à plusieurs. **Git** est l'outil de version control le plus utilisé *(~90%)* dans le monde. **Github** est une des plateformes qui permettent d'héberger un projet **git** gratuitement (Ce site par exemple).<br>

> Google doc contient d'ailleurs une fonctionnalité de version control !
